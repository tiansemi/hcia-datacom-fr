# Prototype — HCIA-Datacom V2.0 (FR)

Test en local :
    pip install -r requirements.txt
    mkdocs serve        # puis ouvrir http://127.0.0.1:8000

Publication : copier ce dossier dans un dépôt GitHub, pousser sur `main`.
Le workflow .github/workflows/deploy.yml construit et publie sur la branche gh-pages.
Puis : Settings > Pages > Source = branche gh-pages.
